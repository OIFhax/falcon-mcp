This module provides tools to retrieve and update Falcon Delivery Settings

## API Scopes

- `delivery-settings:read`
- `delivery-settings:write`

## Tools

### `falcon_get_delivery_settings`

**Required scopes:** `delivery-settings:read`

Retrieve Falcon Delivery Settings.

### `falcon_create_delivery_settings`

> [!NOTE]
> This tool modifies data.

**Required scopes:** `delivery-settings:write`

Create or update Falcon Delivery Settings.
