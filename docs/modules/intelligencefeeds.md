Listing, querying, and downloading intelligence feeds

## API Scopes

- `indicator-graph:read`

## Tools

### `falcon_list_intelligence_feeds`

**Required scopes:** `indicator-graph:read`

List accessible intelligence feed types.

### `falcon_query_intelligence_feed_archives`

**Required scopes:** `indicator-graph:read`

Query accessible feed archives.

### `falcon_download_intelligence_feed_archive`

**Required scopes:** `indicator-graph:read`

Download an intelligence feed archive.
